# Richa Chaurasia · Portfolio

Live site: https://richa-chaurasia.netlify.app
Editor: https://richa-chaurasia.netlify.app/admin

All the words, numbers, projects and pictures live in the `content` and `images` folders,
and you change them through the editor, not here. Every time you press "Publish" in the editor,
the site updates by itself in about a minute.

- `content/site.json` – top of page, About, Contact, footer
- `content/projects.json` – project cards and case studies
- `content/journey.json` – journey, education, certificates
- `content/curiosity.json` – curiosity log cards
- `images/` – every picture
- `freelance/` and `writing/` – the older separate versions (not connected to the editor)
